# ItemPileFFG 0.1.4

Отдельный модуль Foundry VTT 14 для Apex Heresy (`dark-heresy`, версия 1.4.2+): адаптер Item Piles, кредиты, цены, торговцы и вложенные рюкзаки. Riftan Charbar не требуется.

## Установка

В Setup → Add-on Modules → Install Module вставьте:

```text
https://github.com/DarkReef/itempileffg/releases/latest/download/module.json
```

Установите и включите Item Piles, libWrapper и socketlib, затем ItemPileFFG. Откройте инвентарь кнопкой коробки в инструментах токенов или кнопкой в заголовке листа персонажа:

```js
game.modules.get('itempileffg').api.openInventory(canvas.tokens.controlled[0].actor);
```

Модуль сам регистрирует дополнительные поля моделей на этапе `setup`; встроенная версия панели в системе не нужна. Если используется прежняя экспериментальная ветка со встроенной панелью, перейдите на чистую версию системы без встроенного расширения.

## Торговля и контейнеры

Кошелёк хранится в `system.economy.credits`, цена в `system.price`, количество в `system.quantity`. **Исходная цена — 0; перед открытием торговца назначьте цены.** Эта экономика дополняет Влияние/Снабжение и не пересчитывает доступность предмета в деньги автоматически.

Мастер выбирает токен и запускает:

```js
await game.modules.get('itempileffg').api.createMerchantFromSelected();
```

Покупка/продажа, запасы и торговые коэффициенты настраиваются в Item Piles. Кошелёк редактируется мастером в новом инвентаре. Если настройки Item Piles были изменены вручную, проверьте пути валюты, цены и количества в его настройках системы.

«Новый рюкзак» создаёт `gear` вместимостью 20 кг. Любой физический предмет можно назначить контейнером через «Настроить». Контейнер должен быть в одном экземпляре. Вместимость 0 означает отсутствие ограничения. Выбор родителя в строке предмета позволяет вложить предмет в рюкзак, сумку в рюкзак и так далее. Циклы запрещены, вместимость проверяется во всех предках; вес считается один раз.

При перетаскивании рюкзака в Item Piles переносится всё поддерево. При покупке/продаже заполненный рюкзак представляет **один комплект по цене самого рюкзака**. Цена вложенных предметов повторно не списывается. Бесконечный ассортимент копирует комплект. Продажа комплекта и его содержимого отдельными позициями в одной сделке отклоняется.

```js
await game.modules.get('itempileffg').api.moveItem({
  actorUuid: canvas.tokens.controlled[0].actor.uuid,
  itemId: 'ITEM_ID', containerId: 'BAG_ID'
});
```

## Разработка и проверка

Исходники: `modules/itempileffg`. Сборка: `npm run modules:build`; проверки: `npm test`. Пакет имеет собственные язык, CSS и API; не импортирует другой модуль или файлы системы. Поля совместимы с данными предыдущей встроенной версии.

Адаптер сверён с исходниками Item Piles `85ab971406623fb1c5d01eb1f093fe4855ede6e4`. Версия 0.1.1 — тестовый релиз: реальная торговля в многопользовательском Foundry 14 ещё требует проверки. Транзакции записывает Item Piles; запись двух актёров не является атомарной транзакцией базы данных. При отключении модуля данные сохраняются в мире, но исходная система может скрыть добавленные поля.

Основано на коде Apex Heresy, автор Apex; выделение и доработка — DarkReef. Лицензия GPL-3.0, полный текст в `LICENSE`. Исходники опубликованы вместе с релизом в этом репозитории.

## Исправление экономики в существующем мире (0.1.1)

Поле «Стоимость за единицу, кредиты» добавляется прямо в лист любого предмета. Изменение сохраняется сразу; отдельные предметы и разблокированные компендиумы также поддерживаются. `system.cost` (стоимость опыта) не используется. Для торговли действуют прежние ограничения на типы продаваемых предметов; стоимость не отменяет реквизицию Only War.

Пустые настройки цены и валюты Item Piles автоматически исправляет активный мастер. Настроенные пользователем пути сохраняются. Для явного восстановления стандартной экономики мастер может выполнить:

```js
await game.modules.get('itempileffg').api.repairEconomy();
```

Это заменит текущие пути цены/количества и валюту настройками ItemPileFFG; цены самих предметов не меняются. Включите Item Piles, libWrapper и socketlib в управлении модулями мира. Система сама по себе рекомендует Item Piles; обязательная зависимость принадлежит торговому модулю.

## Перенос на карту (0.1.2)

При загрузке мира активный мастер проверяет настройку Item Piles `actorClassType`. Пустой или неизвестный тип исправляется на `acolyte`. Это устраняет ошибку «type: may not be undefined» при создании добычи из перетаскиваемого предмета. Допустимый пользовательский тип сохраняется. После обновления включите ItemPileFFG и перезагрузите мир с подключённым мастером.


В настройках ItemPileFFG задаются название и путь значка валюты. По умолчанию — «Троны». Существующие суммы остаются в system.economy.credits. Мастер выбирает токен, открывает «Рюкзаки и торговля», нажимает «Валюта на карту» и вводит сумму. Создаётся денежная добыча в позиции токена; получение выполняет Item Piles. Для пользовательской валюты с иным путём настройки автоматически не заменяются.

## Раскрываемые рюкзаки и комплекты

- В обычной вкладке снаряжения контейнер раскрывается стрелкой «Содержимое». Внутри могут находиться другие раскрываемые контейнеры. Исходные строки предметов сохраняют штатные действия листа.
- В окне «Рюкзаки и торговля» рядом с рюкзаком появилась стрелка; выбор контейнера для предмета по-прежнему проверяет циклы и вместимость всех предков.
- «Передать» открывает штатный диалог Item Piles. Адаптер включает всё вложенное содержимое. Перетаскивание рюкзака между листами, которыми вы управляете, использует transferItems вместо копирования одной внешней сумки. Для чужого персонажа используйте «Передать» с механизмом согласия Item Piles.
- Покупка заполненного рюкзака у торговца переносит вложенные вещи. Цена внешнего рюкзака считается ценой всего набора; содержимое не оплачивается второй раз. Чтобы продать отдельную вещь, сначала выньте её. Контейнер хранится в одном экземпляре.

Мастер может нажать «Сохранить комплект» у готового рюкзака. В разделе «Предметы» появляется библиотека «Комплекты». Можно также нажать там «Создать комплект» и задать количества предметов из мировой боковой панели; нулевые значения исключаются. Предметы из компендиума сначала импортируйте в мир.

Выберите один токен и нажмите «Выдать выбранному персонажу». При отсутствии выбранного токена используется назначенный персонаж. Шаблон остаётся в библиотеке; создаётся новая сумка со всем содержимым и новыми ID. Название, изображение и цена шаблона применяются к выданной сумке. Изменение состава производится сохранением нового комплекта. Создание и выдача шаблонов доступны мастеру, чтобы игроки не могли бесплатно создавать снаряжение. Комплекты хранятся в документах мира, без ссылок на удаляемые исходные предметы.

Проверено автоматическими тестами (вложенность, повторная выдача, права, двойной клик, торговые обновления и перенос) и браузерным стендом с реальным кодом модуля. Проверка в живом Foundry 14 с Item Piles ещё требуется; транзакции Item Piles между двумя актёрами не являются атомарной операцией базы данных.
