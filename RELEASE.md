# ItemPileFFG 0.2.3

Оружие сохраняет привязку к новым копиям своих боеприпасов при выдаче комплекта, покупке рюкзака с содержимым и передаче между персонажами. Требуется Apex Heresy RU 1.6.1+ для новой модели запасов и загруженного профиля.

- Если запас патронов не передаётся, привязка к чужому инвентарю снимается. Уже заряженные патроны сохраняют записанные название и эффекты.
- Перемещение внутри персонажа сохраняет ID и привязку. При отделении части стопки оружие остаётся связано с исходным остатком.
- Предметы с разными эффектами боеприпаса, единицами количества и состоянием магазина не смешиваются автоматически.
- Старые полные UUID переназначаются только при известном точном источнике; неоднозначная ссылка снимается, а не подбирается по имени или совпавшему ID чужого предмета.

Прежние версии Apex Heresy с ID `dark-heresy` 1.4.2+ сохраняют поддержку обычного инвентаря. Vendare не поддерживается.

Проверки: 42 автоматических теста, включая комплекты, торговлю, разделение стопок, сохранение заряженных эффектов и чужие UUID. Проверка в живом многопользовательском Foundry ещё требуется. Переносы используют Item Piles; локальная очередь модуля не является межклиентской транзакцией.

Установка: https://github.com/DarkReef/itempileffg/releases/latest/download/module.json
