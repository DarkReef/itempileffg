# ItemPileFFG 0.2.2

- Поддержка отдельного пакета Apex Heresy RU `apex-heresy-ru` 1.6.0+; прежний Apex Heresy `dark-heresy` 1.4.2+ остаётся совместимым.
- Инвентарь и карточки предметов работают с обоими ID. Данные контейнеров, количества и классы CSS сохранены без миграции.
- Для нового ID указан манифест DarkReef; ссылка прежнего ID закреплена на релизе системы 1.5.6. Vendare не поддерживается.

Проверки: 37 автоматических тестов. Живая многопользовательская проверка Foundry VTT 14 после смены ID системы ещё требуется. Перенос мира выполняется по инструкции системы.

Установка: https://github.com/DarkReef/itempileffg/releases/latest/download/module.json
